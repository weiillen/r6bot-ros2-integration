# Publication Notes

This folder is prepared as a public GitHub portfolio version of the uploaded `colearn.zip` archive.

## Included

- `docs/r6bot_bottom_up_project_report.pdf`
  - Preserved byte-for-byte from the uploaded archive.
  - Renamed only for a clean repository path.

## Intentionally omitted

The original co-learning-circle closure-report `.docx` is **not included** in the public package because it contains information that should not be casually published in a GitHub repository, including:

- student IDs;
- personal email addresses;
- team administrative information;
- private/shared-drive links.

Its original hash and file size are still recorded in `ORIGINAL_FILE_MANIFEST.tsv` so the source archive can be audited without publishing the document itself.

## Before publishing the PDF

The PDF is a team project report and contains team-member names/reflections and may contain project photographs. Confirm that the team is comfortable with public publication before pushing the report to a public repository. If not, keep the PDF private and publish only the README/project summary.
